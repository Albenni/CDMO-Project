\section{CP Model}

For the Sports Tournament Scheduling problem, we provide two MiniZinc models: a \emph{decision} model (\texttt{sts\_decision.mzn}) and an \emph{optimization} model (\texttt{sts\_opt.mzn}).

Both models use the index sets \text{(with $n$ even)}:
\[
\text{Teams}=\{1,\dots,n\}\,\qquad
\text{Weeks}=\{1,\dots,n-1\},\qquad
\text{Periods}=\{1,\dots,n/2\}.
\]
Additionally, due to the period–load cap ($\le 2$), the decision model restricts $n$ to $(n=2)\vee(n>5)$, which makes $n=4$ not admissible.

\medskip
\noindent\emph{Notation.} We use Iverson brackets $[\,\cdot\,]$ to denote Boolean-to-integer casts (1 if the condition holds, 0 otherwise).

\subsection{Decision variables}

\paragraph{Decision model (\texttt{sts\_decision.mzn}).}
\begin{itemize}
  \item \textbf{Slot–pair assignment ($Z$).}
  We use $Z_{w,p,i,j}\in\{0,1\}$ to indicate whether the unordered pair $\{i,j\}$ (with $i<j$) is scheduled in week $w$ and period $p$. This is the authoritative placement view: all other views of the schedule are derived from $Z$. Keeping $Z$ as the primary source of truth lets us express slot capacity and pair uniqueness as simple sums (detailed later in the constraints), which in turn provides strong propagation.

  \item \textbf{Team–slot occupancy ($U$).}
  We keep $U_{w,p,t}\in\{0,1\}$ to mark whether team $t$ participates in slot $(w,p)$. Although $U$ is derivable from $Z$, making it explicit is useful because it allows us to write “each team plays exactly once per week” and per–period usage directly in a counting form. The link to $Z$ is a channel:
  \[
  U_{w,p,t} \;=\; \sum_{j>t} Z_{w,p,t,j} \;+\; \sum_{i<t} Z_{w,p,i,t},
  \]
  meaning that team $t$ occupies slot $(w,p)$ iff the slot contains either $(t,j)$ with $t<j$ or $(i,t)$ with $i<t$.

  \item \textbf{Output view ($H,A$).}
  The matrices $H_{p,w}, A_{p,w}\in\text{Teams}$ expose the solution in the exact format required by the checker (home team, away team for each period–week). In the \emph{decision} model, we fix the orientation canonically to eliminate the global home/away flip symmetry: the lower team id is home and the higher id is away. This is channeled from $Z$ without disjunctions:
  \[
  H_{p,w} \;=\; \sum_{i<j} Z_{w,p,i,j}\cdot i,
  \qquad
  A_{p,w} \;=\; \sum_{i<j} Z_{w,p,i,j}\cdot j.
  \]
  Consequently, each occupied slot $(w,p)$ contributes exactly one pair $\{i,j\}$ and therefore exactly one pair $(H_{p,w},A_{p,w})$.

  \item \textbf{(Optional) Exact period–usage profile ($C$).}
  When we enforce the implied “exact profile” also in the decision model, we introduce $C_{t,p}\in\{1,2\}$ to count how many times team $t$ uses period $p$ over the season, linked by
  \[
  C_{t,p} \;=\; \sum_{w\in\text{Weeks}} U_{w,p,t}.
  \]
  This redundant view exists solely to encode the per-team profile compactly (one period used once, all others twice) and to strengthen propagation; see the \emph{Implied constraints} paragraph.
\end{itemize}

\paragraph{Optimization model (\texttt{sts\_opt.mzn}).}
The optimization model retains $Z$, $U$, $H$, and $A$ as above, and adds variables that make week assignment, orientation, and period profiles explicit. These dual or aggregated views strengthen propagation and support the fairness objective.

\begin{itemize}
  \item \textbf{Week of each pair ($W$).}
  For every unordered pair we keep $W_{i,j}\in\text{Weeks}$ with $i<j$. This variable expresses the mapping “pair $\to$ week” and is tightly linked to $Z$ by a bidirectional channel:
  \[
  [\,W_{i,j}=w\,] \;=\; \sum_{p\in\text{Periods}} Z_{w,p,i,j}\quad \forall\,w\in\text{Weeks},
  \]
  which is equivalent to saying that choosing $W_{i,j}=w$ places $\{i,j\}$ in exactly one period during week $w$. This dual view enables compact team-wise constraints (e.g., all weeks incident to a team are \texttt{alldifferent}) and provides a strong first search phase.

  \item \textbf{Orientation of each pair ($B$).}
  We define $B_{i,j}\in\{0,1\}$ for $i<j$: by convention $B_{i,j}=1$ means $i$ plays at home against $j$; otherwise $j$ plays at home against $i$. Orientation is reflected in the output by channeling $B$ together with $Z$; at the unique slot $(w,p)$ where $Z_{w,p,i,j}=1$ we set
  \[
  \begin{aligned}
  H_{p,w} &= i\cdot B_{i,j} + j\cdot (1 - B_{i,j}),\\
  A_{p,w} &= j\cdot B_{i,j} + i\cdot (1 - B_{i,j}),
  \end{aligned}
  \]
  and implement this for all slots at once via linear expressions weighted by $Z$. Keeping $B$ explicit allows us to compute fairness and apply symmetry breaking on a fixed reference week.

  \item \textbf{Exact period–usage profile ($C$).}
  The variable $C_{t,p}\in\{1,2\}$ counts how many times team $t$ uses period $p$ over the season. It is defined by summing occupancy across weeks,
  \[
  C_{t,p} \;=\; \sum_{w\in\text{Weeks}} U_{w,p,t},
  \]
  but stating $C$ explicitly helps the solver enforce the intended profile (one period used once, all other periods used twice) with stronger filtering than a simple “$\le 2$” bound.

  \item \textbf{Home counts and deviation ($Hc$, $\mathrm{dev}$).}
  For each team we compute the total number of home matches
  \[
  Hc_t \;=\; \sum_{j>t} B_{t,j} \;+\; \sum_{i<t} (1 - B_{i,t}),
  \]
  which depends only on pair-level orientations $B$. The absolute deviation from the ideal split is linearized with the standard pair of inequalities:
  \[
  \mathrm{dev}_t \;\ge\; 2\,Hc_t - (n-1),\qquad
  \mathrm{dev}_t \;\ge\; -(2\,Hc_t - (n-1)).
  \]
  These variables serve as summary views that exist to make the objective explicit and solver-friendly.

  \item \textbf{Objective accumulator ($\mathrm{obj}$).}
  We keep $\mathrm{obj}\in\mathbb{Z}_{\ge 0}$ as the aggregator of team-wise deviations:
  \[
  \mathrm{obj} \;=\; \sum_{t\in\text{Teams}} \mathrm{dev}_t.
  \]
\end{itemize}

\subsection{Objective function}

The decision model is a pure feasibility formulation (\texttt{solve satisfy}).  
The optimization model minimizes the global home/away imbalance,
\[
\min\ \mathrm{obj},
\]
where $\mathrm{obj}$, $Hc_t$, and $\mathrm{dev}_t$ are exactly as defined in the decision-variables section.

We also post the global equality
\[
\sum_{t\in\text{Teams}} Hc_t \;=\; \frac{n(n-1)}{2},
\]
i.e., total home games equal the total number of matches. While redundant, this constraint lets the solver tighten domains early.

For admissible instances (even $n$), we further add the following objective bounds as pruning cuts:
\[
n \;\le\; \mathrm{obj} \;\le\; 2n \,
\]
The lower bound follows from parity: each team plays $n\!-\!1$ matches (odd), hence $\mathrm{dev}_t\ge 1$ for all $t$, and therefore $\mathrm{obj}\ge n$.

\subsection{Constraints}

Here, we summarize the constraints that both models employ. We make it clear when a constraint is optimization-only. The channels and variables listed below are all specified in the Decision-variables subsection.

\paragraph{Core scheduling constraints (both models).}
These constraints, written against the authoritative placement view $Z$ and the occupancy view $U$, encode the mathematical properties of an everyone-plays-everyone-once season.

\noindent\textit{One match per slot.}
\[
\forall\,w\in\text{Weeks},\ \forall\,p\in\text{Periods}:\quad 
\sum_{1\le i<j\le n} Z_{w,p,i,j} = 1.
\]

\noindent\textit{Each pair exactly once.}
\[
\forall\,1\le i<j\le n:\quad 
\sum_{w\in\text{Weeks}}\sum_{p\in\text{Periods}} Z_{w,p,i,j} = 1.
\]

\noindent\textit{Weekly participation (exactly once).}
\[
\forall\,w\in\text{Weeks},\ \forall\,t\in\text{Teams}:\quad 
\sum_{p\in\text{Periods}} U_{w,p,t} = 1.
\]

\paragraph{Period-usage constraints.}
According to the task, a team must appear in the same period at most twice during the season. We enforce this differently in the two models:

\noindent\textit{Decision model: at-most-two bound (core), with optional exact profile.}
\[
\forall\,t\in\text{Teams},\ \forall\,p\in\text{Periods}:\quad 
\sum_{w\in\text{Weeks}} U_{w,p,t} \le 2.
\]
When the implied profile is enabled, we also use $C_{t,p}=\sum_w U_{w,p,t}$ to encode the exact distribution (see \emph{Implied constraints} below).

\noindent\textit{Optimization model: strengthened profile.}
We adopt the exact per-period profile for each team; see the \emph{Implied constraints} paragraph (\emph{Exact period profile}) for the explicit formulation.

\paragraph{Channeling constraints (consistency between views).}
These equalities keep all views of the schedule synchronized.

\noindent\textit{$U \leftrightarrow Z$ (occupancy from placement).}
\[
\forall\,w,p,t:\quad 
U_{w,p,t} = \sum_{j>t} Z_{w,p,t,j} \;+\; \sum_{i<t} Z_{w,p,i,t}.
\]
This states that team $t$ occupies slot $(w,p)$ iff the slot hosts either $(t,j)$ with $t<j$ or $(i,t)$ with $i<t$.

\noindent\textit{$W \leftrightarrow Z$ (pair-to-week, optimization model).}
\[
\forall\,i<j,\ \forall\,w\in\text{Weeks}:\quad 
\mathbf{1}[W_{i,j}=w] \;=\; \sum_{p\in\text{Periods}} Z_{w,p,i,j}.
\]
Equivalently, each pair chooses exactly one week and is placed in one period of that week.

\noindent\textit{Output construction (decision model).}
\[
H_{p,w} = \sum_{i<j} Z_{w,p,i,j}\, i, 
\qquad 
A_{p,w} = \sum_{i<j} Z_{w,p,i,j}\, j.
\]

\noindent\textit{Output construction (optimization model, orientation-aware).}
\[
H_{p,w} = i\,B_{i,j} + j\,(1-B_{i,j}), 
\qquad 
A_{p,w} = j\,B_{i,j} + i\,(1-B_{i,j}),
\]
\noindent for the unique $(i<j)$ such that $Z_{w,p,i,j}=1$.

\paragraph{Pair-index cleanup (self-matches and duplicates).}
We exclude self-matches and duplicated orientations by using unordered pairs with $i<j$. When arrays are declared over all team indices for convenience, we fix entries with $i\ge j$ to constants so they can never participate in a solution:
\[
\forall\,w,p:\ \forall\,i\ge j:\quad Z_{w,p,i,j}=0 \quad\text{(both models)},
\]
\[
\forall\,i\ge j:\quad B_{i,j}=0,\ \ W_{i,j}=1 \quad\text{(optimization model)}.
\]

\paragraph{Implied constraints.}
The following constraints are \emph{logically implied} by the model semantics but are posted to strengthen propagation and prune search earlier:

\noindent\textit{Exact period profile (per team, both models).}
\[
C_{t,p}=\sum_{w} U_{w,p,t},\quad C_{t,p}\in\{1,2\},\qquad
\sum_{p} C_{t,p}=n-1,\quad \sum_{p} \mathbf{1}[C_{t,p}=1]=1\quad \forall t.
\]
Given $\sum_{p,w} U_{w,p,t}=n-1$ and $\sum_{w} U_{w,p,t}\le 2$, the only feasible distribution is “one period used once and all the others twice”; encoding it explicitly yields stronger propagation.

\noindent\textit{Week-wise distinctness via a global (optimization model).}
\[
\forall\,t\in\text{Teams}:\quad 
\texttt{alldifferent}\Big(\, W_{\min(t,j),\,\max(t,j)} \ \big|\ j\neq t \,\Big).
\]
This is logically equivalent to “exactly once per week” for team $t$, but the global propagator acts directly on week choices and typically prunes earlier.

\noindent\textit{Global home-count balance (optimization model).}
\[
\sum_{t\in\text{Teams}} Hc_t \;=\; \frac{n(n-1)}{2}.
\]
Since every match contributes exactly one home, this equality synchronizes team counters and tightens domains as soon as some orientations are fixed.

\noindent\textit{Objective lower bound (even $n$, optimization model).}
\[
\mathrm{obj} \;\ge\; n.
\]
Each team plays $n-1$ (odd) matches, hence $\mathrm{dev}_t\ge 1$ for all $t$, so the sum of deviations is at least $n$.

\paragraph{Symmetry breaking.}
These constraints remove equivalent schedules without excluding any feasible one.

\noindent\textit{Week~1 canonical pairing (both models).}
\[
\forall\,p\in\text{Periods}:\quad Z_{1,p,\,2p-1,\,2p}=\texttt{true}.
\]

\noindent\textit{Week~1 orientation (optimization model).}
\[
\forall\,p\in\text{Periods}:\quad B_{\,2p-1,\,2p}=\texttt{true}.
\]

\noindent\textit{Canonical home/away in the decision model.}
\[
\forall\,w,p:\quad 
H_{p,w}=\sum_{i<j} Z_{w,p,i,j}\, i,\qquad 
A_{p,w}=\sum_{i<j} Z_{w,p,i,j}\, j.
\]
\noindent(Equivalently, the lower team id is always home and the higher id is away; this kills the global home/away flip symmetry.)

\noindent\textit{Single-use period anchor (optimization model).}
\[
C_{1,1} = 1.
\]
\noindent This fixes team~1's unique single-use period to period~1, breaking the global permutation symmetry among periods without excluding non-equivalent schedules.
\subsection{Validation}

The purpose of this section is to compare the behaviour of the two CP models (decision and optimization) for different solvers and modelling variants (with/without symmetry breaking, with/without implied constraints), in terms of needed time to find the (optimal) solution, within a $300$ seconds limit.

\subsubsection*{Experimental design}

\hspace*{1.5em}\textbf{Instances.} We tested sizes $n\in\{8,10,12,14,16,18\}$.\\
\hspace*{1.5em}\textbf{Solvers.} \texttt{cp-sat}, \texttt{chuffed}, \texttt{gecode}.\\
\hspace*{1.5em}\textbf{Runner and data.} A Python wrapper sets $n$, runs the chosen MiniZinc model/solver, and writes one JSON per instance under \texttt{res/CP/\{n\}.json}, merging approaches as distinct keys (e.g., \texttt{cp-sat\_dec}, \texttt{chuffed\_opt\_noSB}).\\
\hspace*{1.5em}\textbf{Approaches.} For each solver, we assess different approaches by enabling or disabling symmetry breaking (SB) and implied constraints (IC).\\
\hspace*{1.5em}\textbf{Search strategies.}

\noindent\emph{Optimization model.} \textit{Phased search (Trick’s schedule–then–break).}
We separate the structural calendar from orientations and solve in three phases:
\begin{itemize}
  \item[(1)] fix the week of each pair $W$ (\emph{schedule});
  \item[(2)] place pairs $Z$ within the chosen week (\emph{structural refinement});
  \item[(3)] set orientations $B$ (\emph{break}).
\end{itemize}
This stratification follows Trick’s classic \emph{schedule–then–break} rationale for sports timetabling: first construct the weekly round-robin schedule ignoring home/away, then assign orientations to control breaks and fairness. In our CP setting, the idea is that the strongest propagation lives in the structural layer (e.g., team-wise \texttt{alldifferent} across weeks), so we commit those decisions early and defer the cheaper binary choices to the end. We implement the phases with a sequential search:
\[
\begin{aligned}
\texttt{seq\_search}\Big(&
\texttt{int\_search}(W,\ \texttt{dom\_w\_deg},\ \texttt{indomain\_min},\ \texttt{complete}),\\
&\texttt{bool\_search}(Z,\ \texttt{first\_fail},\ \texttt{complete}),\\
&\texttt{bool\_search}(B,\ \texttt{first\_fail},\ \texttt{complete})
\Big).
\end{aligned}
\]
Here, \texttt{dom\_w\_deg} (domain/weighted-degree) prioritises the most constrained/conflict-rich week decisions, while
\texttt{first\_fail} applies a fail-first policy to the Boolean layers; this mirrors the two-phase schedule–then–break approach~\cite{TrickScheduleThenBreak}.

\noindent\emph{Decision model.} Solver defaults (no user-defined search).

\hspace*{1.5em}\textbf{Result format.} Decision tables report the runtime in seconds (if no answer within $300$ s, we write ``$>300$’’).
Optimization tables report, for each entry, \emph{time / objective} (with the objective in \textbf{bold} if proven optimal).
If no solution was obtained within the time limit, we write ``$>300\,/\,\text{--}$’’.

\subsubsection*{Discussion}

\textbf{Decision model.} With SB+Implied on, \texttt{cp-sat} quickly solves up to $n=14$, while \texttt{chuffed} and \texttt{gecode} often time out beyond $n=10$. Turning SB off helps some cases (e.g., $n=10$ where all solvers succeed fast, and $n=16$ where \texttt{cp-sat} finds a solution in $131$ s), but it can significantly hurt \texttt{cp-sat} on mid sizes ($n=12,14$), suggesting that the canonical Week~1 pairing reduces early branching entropy in a way that benefits its SAT-style search. Disabling implied constraints (\emph{noImplied}) systematically helps \texttt{chuffed} on $n\in\{10,12,14\}$ (down to a few seconds), likely because the additional channel/profile constraints increase propagation work that does not always pay back on pure feasibility; \texttt{cp-sat} instead benefits more from the implied structure on mid sizes, except at $n=16$ where \emph{noImplied} becomes advantageous.

\textbf{Optimization model.} With the staged search (dom/wdeg on $W$ first), both \texttt{cp-sat} and \texttt{chuffed} prove optimality up to $n=14$ very quickly; \texttt{gecode} keeps pace up to $n=12$, then times out at $n=14$. This is consistent with expectations: focusing first on the week variables $W$ (tied by \texttt{alldifferent}) turns the hardest propagation layer upfront, after which assigning $Z$ and $B$ is comparatively cheap. Turning SB off does not degrade performance for \texttt{cp-sat} and sometimes helps \texttt{chuffed} confirm optimality at $n=12,14$. Turning off implied constraints weakens pruning; \texttt{cp-sat} still proves optimality up to $n=14$, whereas \texttt{chuffed} and \texttt{gecode} lose robustness earlier.

\textbf{Beyond $n=14$.} For $n\ge 16$ the optimization model returns no solution within the time cap for any solver, and the decision model becomes difficult for all but \texttt{cp-sat} (and only under certain variants). Scaling further would likely require heavier search control (restarts tuning, alternative VOHs) or hybrid search (e.g., LNS seeded by feasible CP solutions).

\medskip
\noindent\textit{Key takeaways.} (1) The staged search focused on $W$ is critical in optimization; (2) \texttt{cp-sat} is the most robust on feasibility; (3) implied constraints are beneficial overall for optimization (stronger propagation), but may slow down easy feasibility, especially for \texttt{chuffed}; (4) symmetry breaking improves consistency and interpretability, yet its ablation can occasionally help first-solution time in SAT-style search—tuning is solver-dependent.

\subsection{SAT Model}

We encode STS in propositional CNF using two families of literals. The solver interface supports Z3 (direct CNF loading) and PySAT backends (DIMACS export with MiniSAT\,22/Glucose\,3). All runs use a $300$s time limit, counted from CNF generation (when applicable), and results are written under \texttt{res/SAT/\#}.json in the format required by the project (\texttt{time}, \texttt{optimal}, \texttt{obj}, \texttt{sol}).

\paragraph{Indexing.}
Let $n$ be even. We use \emph{Teams} $=\{1,\dots,n\}$, \emph{Weeks} $=\{1,\dots,n-1\}$, and \emph{Periods} $=\{1,\dots,n/2\}$. A schedule is an $(n/2)\times(n-1)$ matrix whose entry $(p,w)$ holds exactly one oriented match $(i,j)$ with $i$ at home and $j$ away.

\subsubsection*{Decision variables (literals)}
\begin{itemize}
\item \textbf{Placement with orientation} $X_{i,j,w,p}$ (Boolean): true iff the match ``$i$ vs.\ $j$'' is played in week $w$, period $p$, with $i$ at home (ordered pair, $i\ne j$). This is the authoritative view of the schedule.
\item \textbf{Slot occupancy} $Y_{t,w,p}$ (Boolean): true iff team $t$ occupies slot $(w,p)$. These literals are channeled to $X$ locally (one opponent per team per week).
\end{itemize}

\paragraph{Cardinality encodings.}
We generate CNF for AtMost/ExactlyOne using adaptive encodings: pairwise for $\text{AtMost}(k\!=\!1)$ on small scopes, ladder otherwise; for larger scopes we optionally use \texttt{cardnetwrk}; sequential counters are the default fall-back. This balances clause/auxiliary-variable overhead and propagation strength.

\subsubsection*{Constraints (decision model)}
All constraints are posted in CNF against $X$ and $Y$.

\paragraph{Week assignment by circle method (global pruning).}
We pre-fix the \emph{week} of every unordered pair $\{u,v\}$ by the classical circle construction, then ban all other weeks with unit negatives; within the assigned week we enforce \textsf{ExactlyOne} over all $(w^\star,p)$ and both orientations $(u,v)/(v,u)$:
\[
\sum_{p} \bigl( X_{u,v,w^\star,p} + X_{v,u,w^\star,p} \bigr) = 1,\qquad
X_{u,v,w,p}=X_{v,u,w,p}=0\ \ (\forall w\ne w^\star).
\]
This removes week permutations while keeping at least one feasible schedule.

\paragraph{Channeling $X\leftrightarrow Y$ (one opponent per week).}
Let $o(t,w)$ be the unique opponent of $t$ in week $w$ induced by the circle method. For each $(t,w,p)$:
\[
\bigl(X_{t,o,w,p}\!\!\rightarrow\! Y_{t,w,p}\bigr)\ \wedge\ \bigl(X_{o,t,w,p}\!\!\rightarrow\! Y_{t,w,p}\bigr)\ \wedge\ \bigl(Y_{t,w,p}\!\!\rightarrow\! (X_{t,o,w,p}\vee X_{o,t,w,p})\bigr).
\]
These are 2–3 literal clauses, hence cheap and strong.

\paragraph{Exactly one period per team per week.}
For each $(t,w)$ we post \textsf{ExactlyOne}$\{Y_{t,w,p}\}_{p}$, which implies “one match per team per week” once combined with channeling.

\paragraph{Exactly two teams per slot.}
For each $(w,p)$ we enforce $\sum_t Y_{t,w,p}=2$ via AtMost2 and its dual (AtLeast2 encoded as AtMost on negated literals). This realizes “one match per slot.”

\paragraph{Period load cap.}
For each team $t$ and period $p$, $\sum_w Y_{t,w,p}\le 2$.

\paragraph{Extra symmetry breaking (toggle).}
When enabled, week~1 is fixed at period granularity (pair $\,(i,n\!+\!1\!-\!i)\,$ plays in period $i$) and the match $(1,n)$ is oriented as home for team 1 in $(w,p)=(1,1)$. This removes residual week/period symmetries and follows the modelling advice on symmetry breaking for Round Robin-style encodings~\cite{martins-impact-sat-modelling}.

\subsubsection*{Optimization in SAT (fairness)}
We minimize the maximum home/away imbalance
\[
d^\star \;=\; \min\, d \quad\text{s.t.}\quad \Big\lceil \tfrac{T-d}{2} \Big\rceil \ \le\ \text{home}_i\ \le\ \Big\lfloor \tfrac{T+d}{2} \Big\rfloor\quad\forall i,
\]
where $T=n\!-\!1$ and $\text{home}_i=\sum_{j\ne i,w,p} X_{i,j,w,p}$. We solve this by \emph{incremental} SAT on $d=1,2,\dots,T$ (parity gives $d\ge 1$): for a fixed $d$ we add team-wise upper/lower cardinality constraints on the \emph{home} literals of each team and test satisfiability. The first satisfiable $d$ is optimal. For Z3 we push/pop AtMost/AtLeast constraints; for PySAT we export the base CNF once and then call the solver with the extra fairness clauses.

\subsubsection*{Solvers and interfaces}
\textbf{Z3.} We declare Boolean atoms $v_1,\dots,v_{V}$ and post each CNF clause as a Z3 disjunction; the $300$s limit is passed as a per-call timeout in milliseconds.
\textbf{PySAT backends.} We export CNF to DIMACS (\texttt{pysat.formula.CNF.to\_file}) and run the selected solver with a hard timeout using \texttt{solve\_limited} plus a watchdog \texttt{interrupt}; for optimization we reuse the same DIMACS and add per-$d$ fairness clauses. All solvers are used sequentially, as required.

\subsubsection*{Solution format and JSON writing}
A satisfying assignment is decoded into an $(n/2)\times(n-1)$ matrix of pairs \texttt{[home, away]} by scanning the true $X$ literals. Each run is appended as a new key in \texttt{res/SAT/\#}.json, with time normalized to \texttt{min(actual, 300)} and \texttt{optimal} set according to the decision/optimization semantics.

\paragraph{Why these modelling choices?}
Symmetry breaking and encoding selection strongly affect SAT performance; we deliberately (i) fix a canonical week assignment via the circle method, (ii) keep local $X\!\leftrightarrow\!Y$ channels to obtain short clauses, and (iii) adapt cardinality encodings to scope/threshold. These choices are consistent with the recommendations on the impact of modelling (and symmetry breaking) in SAT problem solving~\cite{martins-impact-sat-modelling}.

\subsubsection*{Validation setup}
We follow the project rules: $300$s global limit including any pre-solving/printing; solvers run on a single core; and Z3 is mandatory while PySAT+DIMACS enables solver-independence. We report decision runtimes and, for optimization, the (best) objective value found within the limit; unsolved cases are marked with time $=300$ and \texttt{optimal=false}.

\section{MIP Model}

\subsection{Decision variables}

The model involves two main groups of binary decision variables, each belonging to a different stage of the two-step Mixed Integer Programming (MIP) formulation.

\paragraph{Stage A (Feasibility model).} 
\begin{itemize}
    \item \textbf{Variable:} $x_{i,j,w,p} \in \{0,1\}$ 
    \item \textbf{Domain:} Binary
    \item \textbf{Semantics:} 
    \[
    x_{i,j,w,p} = 
    \begin{cases}
        1 & \text{if the match between teams } i \text{ and } j \text{ in week } w \text{ is assigned to period } p,\\
        0 & \text{otherwise.}
    \end{cases}
    \]
    \item \textbf{Indices:} 
    \[
    i,j \in \{1,\dots,n\}, \quad i < j, \quad w \in \{1,\dots,n-1\}, \quad p \in \{1,\dots,n/2\}.
    \]
\end{itemize}
The variable defines the temporal and spatial positioning of all matches within the tournament grid, ensuring that each game is played exactly once and that each slot (week–period pair) hosts a single match.

\paragraph{Stage B (Objective model – Home/Away balance).} 
\begin{itemize}
    \item \textbf{Variable:} $s_{i,j,w} \in \{0,1\}$ 
    \item \textbf{Domain:} Binary
    \item \textbf{Semantics:}
    \[
    s_{i,j,w} = 
    \begin{cases}
        1 & \text{if team } i \text{ (the lower index in } (i,j)) \text{ plays at home in week } w,\\
        0 & \text{otherwise.}
    \end{cases}
    \]
    \item \textbf{Variable:} $\mathrm{dev}_i \geq 0$
    \item \textbf{Domain:} Non-negative reals
    \item \textbf{Semantics:} Represents the deviation of team $i$ from the ideal number of home games, 
    \[
    \text{target} = \frac{n-1}{2}.
    \]
\end{itemize}

Thus, Stage~A guarantees \textit{feasibility} of the schedule, while Stage~B optimizes \textit{fairness} in home/away distribution.

---

\subsection{Objective function}

The goal is to minimize the total deviation of the number of home games from the ideal target value for all teams:
\begin{equation}
    \min \sum_{i=1}^{n} \mathrm{dev}_i
\end{equation}
subject to:
\begin{align}
    \mathrm{home}_i - \mathrm{target} &\leq \mathrm{dev}_i, \quad \forall i \in T, \\
    \mathrm{target} - \mathrm{home}_i &\leq \mathrm{dev}_i, \quad \forall i \in T,
\end{align}
where
\begin{equation}
\mathrm{home}_i = 
\sum_{(a,b,w) \in E_W}
\begin{cases}
s_{a,b,w} & \text{if } a = i,\\[2pt]
(1 - s_{a,b,w}) & \text{if } b = i,\\[2pt]
0 & \text{otherwise.}
\end{cases}
\end{equation}

The variable $\mathrm{home}_i$ counts how many matches team $i$ plays at home.  
The target $(n-1)/2$ corresponds to an ideally balanced schedule where each team plays half of its matches at home.  
Thus, the objective minimizes the \emph{sum of absolute deviations} to ensure the fairest possible schedule.

\subsection{Constraints}

\begin{enumerate}
    \item \textbf{One period per match:}
    \begin{equation}
        \sum_{p=1}^{n/2} x_{i,j,w,p} = 1, \quad \forall (i,j,w) \in E_W.
    \end{equation}

    Each match is assigned to exactly one period in its corresponding week.

    \item \textbf{One match per slot:}
    \begin{equation}
        \sum_{\substack{(i,j,ww) \in E_W \\ ww=w}} x_{i,j,ww,p} = 1, 
        \quad \forall w \in W, \; \forall p \in P.
    \end{equation}
    Ensures that each (week, period) slot is occupied by one and only one match.

    \item \textbf{Period cap constraint:}
    \begin{equation}
        \sum_{\substack{(a,b,w) \in E_W \\ a=i \text{ or } b=i}} x_{a,b,w,p} \leq 2, 
        \quad \forall i \in T, \; \forall p \in P.
    \end{equation}
    Each team can appear in the same period at most twice over the entire tournament.

    \item \textbf{Team-week participation:}
    \begin{equation}
        \sum_{\substack{(a,b,ww)\in E_W \\ ww=w, \, (a=i \text{ or } b=i)}}
        \sum_{p=1}^{n/2} x_{a,b,ww,p} = 1, 
        \quad \forall i \in T, \; \forall w \in W.
    \end{equation}
    Guarantees that every team plays exactly one match per week.
\end{enumerate}

\paragraph{Implied constraints.}
Some constraints are structurally implied by the round-robin construction:
\begin{itemize}
    \item Each team faces every other team exactly once, as guaranteed by the generated match set $E_W$.
    \item Each week automatically contains $n/2$ matches, implying a total of $n(n-1)/2$ games.
\end{itemize}
These properties make additional uniqueness constraints unnecessary and improve solver efficiency.


\paragraph{Symmetry breaking constraints.}

The model exhibits symmetry since multiple equivalent schedules exist due to:
\begin{itemize}
    \item permutation of weeks and periods;
    \item global inversion of all home/away assignments.
\end{itemize}

To eliminate such redundancies:
\begin{itemize}
    \item In Stage~A, we fix the first week's match--period mapping:
    \[
    x_{i,j,1,p} = 1 \text{ for the } p\text{-th match of week 1.}
    \]
    \item In Stage~B, we fix the home orientation of one match:
    \[
    s_{i,j,1} = 1 \text{ for the first match of week 1.}
    \]
\end{itemize}
These symmetry-breaking constraints drastically reduce the number of equivalent solutions and improve solver convergence.

\subsection{Validation}

The model was implemented in \texttt{Pyomo}, a Python-based algebraic modeling language, and validated using the \texttt{HiGHS} and \texttt{CBC} solvers.

The validation procedure included:
\begin{itemize}
    \item Running both stages sequentially within a total time limit of 300 seconds, split between Stage~A and Stage~B.
    \item Comparing configurations with and without:
    \begin{itemize}
        \item warm-start initialization (greedy constructive heuristic),
        \item symmetry-breaking constraints.
    \end{itemize}
\end{itemize}

Empirical results confirmed that:
\begin{itemize}
    \item Symmetry breaking significantly reduced solver times, especially for $n \geq 10$.
    \item Warm-start initialization provided high-quality feasible starting points, improving stability.
    \item The two-stage decomposition allowed the model to scale up to $n = 14$ within the 300-second limit.
\end{itemize}

Both stages consistently produced valid tournament schedules satisfying all structural constraints, with home/away deviations typically within one game per team, confirming both feasibility and fairness of the approach.
