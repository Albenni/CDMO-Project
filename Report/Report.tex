\section{CP Model}

We provide two MiniZinc models for the Sports Tournament Scheduling (STS) problem:
a \emph{decision} model (\texttt{sts\_decision.mzn}) and an \emph{optimization} model (\texttt{sts\_opt.mzn}).
Both use the canonical index sets
$\text{Teams}=\{1,\dots,n\}$ (with $n$ even), $\text{Weeks}=\{1,\dots,n-1\}$,
$\text{Periods}=\{1,\dots,n/2\}$.
The decision model additionally restricts $n$ to $(n=2)\vee(n>5)$ due to the period–load cap ($\le 2$), which makes $n=4$ infeasible.

\subsection{Decision variables}
\paragraph{Common notation and index cleanup (rectangular arrays).}
We keep arrays over rectangular index sets and disable meaningless cells by fixing them to constants.
In particular, we only model unordered pairs and forbid $i\ge j$ by setting $Z[w,p,i,j]=0$;
in the optimization model we also set $B[i,j]=0$ and $W[i,j]=1$ for $i\ge j$.
This preserves rectangular arrays while removing free variables.

\paragraph{Decision model (\texttt{sts\_decision.mzn}).}
\begin{itemize}
  \item \textbf{Slot--pair assignment.}
  $Z_{w,p,i,j}\in\{0,1\}$ for $w\in\text{Weeks}$, $p\in\text{Periods}$, $1\le i<j\le n$.
  Semantics: $Z_{w,p,i,j}=1$ iff slot $(w,p)$ hosts the unordered pair $\{i,j\}$.
  \item \textbf{Team--slot occupancy.}
  $U_{w,p,t}\in\{0,1\}$ for $w\in\text{Weeks}$, $p\in\text{Periods}$, $t\in\text{Teams}$.
  Semantics: $U_{w,p,t}=1$ iff team $t$ plays in slot $(w,p)$ (either side).
  \item \textbf{Output view (home/away).}
  $H_{p,w},A_{p,w}\in\text{Teams}$.
  Semantics: values exposed to the checker; in the decision model they are
  \emph{canonically derived} from $Z$ by $H_{p,w}=\min\{i,j\}$,
  $A_{p,w}=\max\{i,j\}$ for the unique $(i<j)$ with $Z_{w,p,i,j}=1$.
\end{itemize}

\paragraph{Optimization model (\texttt{sts\_opt.mzn}).}
\begin{itemize}
  \item \textbf{Same $Z$ and $U$} as above, with the same domains and meaning.
  \item \textbf{Week of each pair (dual viewpoint).}
  $W_{i,j}\in\text{Weeks}$ for $1\le i<j\le n$.
  Semantics: week in which the pair $\{i,j\}$ is played.
  \item \textbf{Orientation (home/away) of each pair.}
  $B_{i,j}\in\{0,1\}$ for $i<j$.
  Semantics: $B_{i,j}=1\Rightarrow i$ is home vs.\ $j$; otherwise $j$ is home vs.\ $i$.
  \item \textbf{Exact period--usage profile.}
  $C_{t,p}\in\{1,2\}$ for $t\in\text{Teams}$, $p\in\text{Periods}$.
  Semantics: number of appearances of team $t$ in period $p$ across the season.
  \item \textbf{Output view (home/away).}
  $H_{p,w},A_{p,w}\in\text{Teams}$.
  Semantics: values exposed to the checker, \emph{derived} from $(Z,B)$ without disjunctions.
  \item \textbf{Home counts and deviation.}
  $Hc_t\in\{0,\dots,n-1\}$ for $t\in\text{Teams}$ (home matches of $t$);
  $\text{dev}_t\in\{1,\dots,n-1\}$ (absolute imbalance of $t$).
  \item \textbf{Objective.}
  $\text{obj}\in\{0,\dots,n(n-1)\}$ with $\text{obj}=\sum_{t} \text{dev}_t$.
\end{itemize}

\subsection{Objective function}
The decision model is a pure feasibility formulation (\texttt{solve satisfy}).

The optimization model minimizes the global home/away imbalance:
\[
\min\ \text{obj}=\sum_{t\in\text{Teams}}\text{dev}_t,
\]
where the home count is computed as
\[
Hc_t=\sum_{j>t} B_{t,j}+\sum_{i<t} (1-B_{i,t}),
\]
and the absolute deviation is linearized via
\[
\text{dev}_t\ \ge\ 2Hc_t-(n-1),\qquad
\text{dev}_t\ \ge\ -(2Hc_t-(n-1)).
\]
We also add the redundant global equality $\sum_t Hc_t = \frac{n(n-1)}{2}$ (total homes equals the number of matches),
and bound the objective as $n\le \text{obj}\le 2n$ (even $n$), which prunes clearly suboptimal branches without forcing feasibility-at-optimum.

\subsection{Constraints}

\paragraph{Main problem constraints.}
\begin{align*}
&\textbf{(one match per slot)} && \forall w\in\text{Weeks},\ \forall p\in\text{Periods}:
&& \sum_{1\le i<j\le n} Z_{w,p,i,j} = 1.\\[4pt]
&\textbf{(each pair once)} && \forall\,1\le i<j\le n:
&& \sum_{w\in\text{Weeks}}\sum_{p\in\text{Periods}} Z_{w,p,i,j}=1.\\[4pt]
&\textbf{(weekly participation)} && \forall w\in\text{Weeks},\ \forall t\in\text{Teams}:
&& \sum_{p\in\text{Periods}} U_{w,p,t} = 1.\\[4pt]
&\textbf{(period load cap)} && \forall t\in\text{Teams},\ \forall p\in\text{Periods}:
&& \sum_{w\in\text{Weeks}} U_{w,p,t}\ \le\ 2.\\[6pt]
&\textbf{(channeling $U\!\leftrightarrow\! Z$)} && \forall w,p,t:
&& U_{w,p,t}=\sum_{j>t} Z_{w,p,t,j}+\sum_{i<t} Z_{w,p,i,t}.
\end{align*}

\paragraph{Optimization-specific constraints (dual viewpoint and globals).}
We use $\mathbf{1}[\cdot]$ for indicator functions ($1$ if the predicate holds, $0$ otherwise).
\begin{align*}
&\textbf{(channeling $W\!\leftrightarrow\! Z$)} && \forall i<j:\quad \sum_{w} \mathbf{1}[W_{i,j}=w]=1,
\qquad \forall w:\ \mathbf{1}[W_{i,j}=w]=\sum_{p} Z_{w,p,i,j}.\\[4pt]
&\textbf{(alldifferent on weeks per team)} && \forall t\in\text{Teams}:\quad
\texttt{alldifferent}\Big(\,[W_{\min(t,j),\max(t,j)}\mid j\neq t]\,\Big).\\[4pt]
&\textbf{(output construction $Z,B\!\Rightarrow\!(H,A)$)} && \forall w,p:
&& \text{$H_{p,w}$ and $A_{p,w}$ are selected from the unique $\{i,j\}$ in $(w,p)$ according to $B_{i,j}$.}
\end{align*}

\paragraph{Implied constraints.}
\begin{align*}
&\textbf{(exact period profile)} && \forall t,p:\quad C_{t,p}=\sum_{w} U_{w,p,t},\quad C_{t,p}\in\{1,2\},\\
&&& \forall t:\quad \sum_{p} C_{t,p}=n-1,\quad \sum_{p} \mathbf{1}[C_{t,p}=1]=1.
\end{align*}
Rationale: with $P=n/2$ periods and the cap $\sum_w U_{w,p,t}\le 2$, arithmetic implies that each team uses exactly one period once and all others twice; encoding this profile strengthens propagation compared to a plain ``$\le 2$'' bound.
We also keep the redundant equality $\sum_t Hc_t = \frac{n(n-1)}{2}$ (already mentioned in the objective section) to aid propagation.

\paragraph{Symmetry breaking constraints.}
\begin{itemize}
  \item \textbf{Week 1 canonical pairing (both models):}
  fix Week~1 to $(1,2),(3,4),\dots,(n-1,n)$ by $Z_{1,p,2p-1,2p}=\texttt{true}$ for all $p$.
  \item \textbf{Week 1 orientation (optimization model):}
  set $B_{2p-1,2p}=\texttt{true}$ for all $p$, i.e., the odd-indexed team is home in Week~1.
  \item \textbf{Canonical home/away in the decision model:}
  $H=\min,\,A=\max$ in every slot removes the global flip symmetry.
\end{itemize}

\section{MIP Model}

\subsection{Decision variables}

The model involves two main groups of binary decision variables, each belonging to a different stage of the two-step Mixed Integer Programming (MIP) formulation.

\paragraph{Stage A (Feasibility model).} 
\begin{itemize}
    \item \textbf{Variable:} $x_{i,j,w,p} \in \{0,1\}$ 
    \item \textbf{Domain:} Binary
    \item \textbf{Semantics:} 
    \[
    x_{i,j,w,p} = 
    \begin{cases}
        1 & \text{if the match between teams } i \text{ and } j \text{ in week } w \text{ is assigned to period } p,\\
        0 & \text{otherwise.}
    \end{cases}
    \]
    \item \textbf{Indices:} 
    \[
    i,j \in \{1,\dots,n\}, \quad i < j, \quad w \in \{1,\dots,n-1\}, \quad p \in \{1,\dots,n/2\}.
    \]
\end{itemize}
The variable defines the temporal and spatial positioning of all matches within the tournament grid, ensuring that each game is played exactly once and that each slot (week–period pair) hosts a single match.

\paragraph{Stage B (Objective model – Home/Away balance).} 
\begin{itemize}
    \item \textbf{Variable:} $s_{i,j,w} \in \{0,1\}$ 
    \item \textbf{Domain:} Binary
    \item \textbf{Semantics:}
    \[
    s_{i,j,w} = 
    \begin{cases}
        1 & \text{if team } i \text{ (the lower index in } (i,j)) \text{ plays at home in week } w,\\
        0 & \text{otherwise.}
    \end{cases}
    \]
    \item \textbf{Variable:} $\mathrm{dev}_i \geq 0$
    \item \textbf{Domain:} Non-negative reals
    \item \textbf{Semantics:} Represents the deviation of team $i$ from the ideal number of home games, 
    \[
    \text{target} = \frac{n-1}{2}.
    \]
\end{itemize}

Thus, Stage~A guarantees \textit{feasibility} of the schedule, while Stage~B optimizes \textit{fairness} in home/away distribution.

---

\subsection{Objective function}

The goal is to minimize the total deviation of the number of home games from the ideal target value for all teams:
\begin{equation}
    \min \sum_{i=1}^{n} \mathrm{dev}_i
\end{equation}
subject to:
\begin{align}
    \mathrm{home}_i - \mathrm{target} &\leq \mathrm{dev}_i, \quad \forall i \in T, \\
    \mathrm{target} - \mathrm{home}_i &\leq \mathrm{dev}_i, \quad \forall i \in T,
\end{align}
where
\begin{equation}
\mathrm{home}_i = 
\sum_{(a,b,w) \in E_W}
\begin{cases}
s_{a,b,w} & \text{if } a = i,\\[2pt]
(1 - s_{a,b,w}) & \text{if } b = i,\\[2pt]
0 & \text{otherwise.}
\end{cases}
\end{equation}

The variable $\mathrm{home}_i$ counts how many matches team $i$ plays at home.  
The target $(n-1)/2$ corresponds to an ideally balanced schedule where each team plays half of its matches at home.  
Thus, the objective minimizes the \emph{sum of absolute deviations} to ensure the fairest possible schedule.

\subsection{Constraints}

\begin{enumerate}
    \item \textbf{One period per match:}
    \begin{equation}
        \sum_{p=1}^{n/2} x_{i,j,w,p} = 1, \quad \forall (i,j,w) \in E_W.
    \end{equation}

    Each match is assigned to exactly one period in its corresponding week.

    \item \textbf{One match per slot:}
    \begin{equation}
        \sum_{\substack{(i,j,ww) \in E_W \\ ww=w}} x_{i,j,ww,p} = 1, 
        \quad \forall w \in W, \; \forall p \in P.
    \end{equation}
    Ensures that each (week, period) slot is occupied by one and only one match.

    \item \textbf{Period cap constraint:}
    \begin{equation}
        \sum_{\substack{(a,b,w) \in E_W \\ a=i \text{ or } b=i}} x_{a,b,w,p} \leq 2, 
        \quad \forall i \in T, \; \forall p \in P.
    \end{equation}
    Each team can appear in the same period at most twice over the entire tournament.

    \item \textbf{Team-week participation:}
    \begin{equation}
        \sum_{\substack{(a,b,ww)\in E_W \\ ww=w, \, (a=i \text{ or } b=i)}}
        \sum_{p=1}^{n/2} x_{a,b,ww,p} = 1, 
        \quad \forall i \in T, \; \forall w \in W.
    \end{equation}
    Guarantees that every team plays exactly one match per week.
\end{enumerate}

\paragraph{Implied constraints.}
Some constraints are structurally implied by the round-robin construction:
\begin{itemize}
    \item Each team faces every other team exactly once, as guaranteed by the generated match set $E_W$.
    \item Each week automatically contains $n/2$ matches, implying a total of $n(n-1)/2$ games.
\end{itemize}
These properties make additional uniqueness constraints unnecessary and improve solver efficiency.


\paragraph{Symmetry breaking constraints.}

The model exhibits symmetry since multiple equivalent schedules exist due to:
\begin{itemize}
    \item permutation of weeks and periods;
    \item global inversion of all home/away assignments.
\end{itemize}

To eliminate such redundancies:
\begin{itemize}
    \item In Stage~A, we fix the first week's match--period mapping:
    \[
    x_{i,j,1,p} = 1 \text{ for the } p\text{-th match of week 1.}
    \]
    \item In Stage~B, we fix the home orientation of one match:
    \[
    s_{i,j,1} = 1 \text{ for the first match of week 1.}
    \]
\end{itemize}
These symmetry-breaking constraints drastically reduce the number of equivalent solutions and improve solver convergence.

\subsection{Validation}

The model was implemented in \texttt{Pyomo}, a Python-based algebraic modeling language, and validated using the \texttt{HiGHS} and \texttt{CBC} solvers.

The validation procedure included:
\begin{itemize}
    \item Running both stages sequentially within a total time limit of 300 seconds, split between Stage~A and Stage~B.
    \item Comparing configurations with and without:
    \begin{itemize}
        \item warm-start initialization (greedy constructive heuristic),
        \item symmetry-breaking constraints.
    \end{itemize}
\end{itemize}

Empirical results confirmed that:
\begin{itemize}
    \item Symmetry breaking significantly reduced solver times, especially for $n \geq 10$.
    \item Warm-start initialization provided high-quality feasible starting points, improving stability.
    \item The two-stage decomposition allowed the model to scale up to $n = 14$ within the 300-second limit.
\end{itemize}

Both stages consistently produced valid tournament schedules satisfying all structural constraints, with home/away deviations typically within one game per team, confirming both feasibility and fairness of the approach.
